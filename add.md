# Add Program: Code Flow and Explanation

## Program

```python
a = 4
n = 4
v = n + a
print(v)
```

## Code Flow

1. `a = 4` creates the variable `a` and stores the number `4` in it.
2. `n = 4` creates the variable `n` and stores the number `4` in it.
3. `v = n + a` adds the values in `n` and `a` (`4 + 4`) and stores the result, `8`, in `v`.
4. `print(v)` displays the value of `v` in the terminal.

## Output

```text
8
```

The program adds two numbers and prints their sum.
